Accessibility Statement

Peak Property Performance® is committed to ensuring digital accessibility for people with disabilities. We are continually improving the user experience for everyone and applying the relevant accessibility standards.

Conformance Status

The Web Content Accessibility Guidelines (WCAG) define requirements for designers and developers to improve accessibility for people with disabilities. It defines three levels of conformance: Level A, Level AA, and Level AAA.

peakpropertyperformance.com is partially conformant with WCAG 2.1 Level AA. Partially conformant means that some parts of the content do not fully conform to the accessibility standard.

Measures Taken

Peak Property Performance® takes the following measures to ensure accessibility:

  • Skip navigation link on every page
  • Semantic HTML structure with proper heading hierarchy
  • ARIA landmarks, labels, and roles on navigation, main content, and footer
  • Keyboard-accessible navigation with visible focus indicators on all interactive elements
  • Focus trapping in modal dialogs (cookie consent)
  • Color contrast ratios meeting WCAG 2.1 AA minimums (4.5:1 for normal text, 3:1 for large text)
  • Meaningful alternative text on all content images; decorative images marked with empty alt
  • Respects prefers-reduced-motion to disable animations for users who request it
  • Automated accessibility testing with pa11y-ci against WCAG 2.1 AA rules

Known Limitations

Despite our best efforts, some content may not yet be fully accessible:

  • Third-party embeds: Embedded podcast players (Spotify, Apple Podcasts) and YouTube video facades are governed by their respective platforms' accessibility implementations.
  • PDF documents: Some downloadable resources may not be fully tagged for screen readers. We are working to remediate these.
  • Legacy content: Some pages exported from our previous CMS may contain residual markup that does not fully meet AA requirements.

Feedback

We welcome your feedback on the accessibility of peakpropertyperformance.com. If you encounter accessibility barriers, please let us know:

  • Website: opticwise.com/contact
  • Email: accessibility@opticwise.com

We try to respond to accessibility feedback within 5 business days.

Technical Specifications

Accessibility of peakpropertyperformance.com relies on the following technologies:

  • HTML
  • WAI-ARIA
  • CSS
  • JavaScript

These technologies are relied upon for conformance with the accessibility standards used.

Assessment Approach

Peak Property Performance® assessed the accessibility of this site using the following approaches:

  • Self-evaluation using axe-core automated testing engine
  • Automated CI testing with pa11y-ci against WCAG 2.1 AA ruleset
  • Manual keyboard navigation testing
  • Screen reader testing (VoiceOver on macOS)
